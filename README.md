# Prompt Cloud

مكتبة عربية مفتوحة المصدر لإدارة المطالبات والصور المرجعية محليًا في المتصفح.

## المزايا
- React + TypeScript + Vite + Tailwind CSS
- تخزين Dexie / IndexedDB محليًا بدون حسابات أو خادم بيانات
- تصنيفات ومطالبات وصور متعددة مع بحث ونسخ وتعديل وحذف
- تصدير واستيراد مكتبة كاملة في ملف JSON واحد، يشمل الصور بصيغة Base64
- واجهة عربية RTL متجاوبة مع الهواتف والحواسيب
- رخصة MIT

## التشغيل
```bash
npm ci
npm run dev
npx tsc --noEmit
npm run build
npm run preview
```

## النشر عبر GitHub Pages
1. أنشئ مستودعًا عامًا باسم `Prompt-Cloud` وارفع ملفات المشروع إلى الفرع `main`.
2. من Settings → Pages → Build and deployment اختر **GitHub Actions**.
3. سيبني Workflow المشروع وينشر مجلد `dist` تلقائيًا عند كل push.
4. الرابط: `https://USERNAME.github.io/Prompt-Cloud/`.

يُضبط `VITE_BASE_PATH` في GitHub Actions تلقائيًا وفق اسم المستودع. عند النشر على نطاق مخصص، اضبط `VITE_BASE_PATH=/` في Workflow وأضف ملف `public/CNAME` باسم النطاق، ثم اضبط DNS من GitHub Pages.

## البيانات والخصوصية
لا يرسل التطبيق المطالبات أو التصنيفات أو الصور إلى أي خادم. تُخزّن البيانات في IndexedDB تحت أصل الموقع الحالي؛ وقد تُحذف عند تنظيف بيانات المتصفح أو تغيير الجهاز أو استخدام الوضع الخاص. GitHub Pages يقدم الملفات الثابتة فقط، وقد تسري سجلات طلبات الاستضافة الاعتيادية لدى GitHub. لا توجد Analytics أو Tracking داخل التطبيق.

## النسخ الاحتياطي والاستعادة
زر **النسخ الاحتياطي** → **تصدير النسخة الاحتياطية** يُنشئ JSON يحتوي على جميع التصنيفات والمطالبات والصور، مع حفظ المعرّفات والتواريخ والنصوص. استيراد ملف صالح ثم الموافقة يستبدل المكتبة المحلية بالكامل داخل معاملة Dexie واحدة. الصور تُخزّن كـ Blob محليًا، ولا تتحول إلى Data URLs إلا عند التصدير والاستيراد. لا ترفع ملفات النسخ الاحتياطية إلى المستودع.

الصيغة الأساسية:
```json
{"app":"Prompt Cloud","schemaVersion":1,"exportedAt":"2026-11-19T00:00:00.000Z","categories":[],"prompts":[]}
```

الفئة: `id, name, createdAt, updatedAt`.
المطالبة: `id, categoryId, title, content, images, createdAt, updatedAt`.
الصورة في ملف النسخة: `id, name, type, dataUrl`.

**تنبيه:** نسخة JSON تحتوي على المحتوى والصور بصيغة مقروءة؛ احفظها في مكان آمن. قد يحد المتصفح من حجم ملفات JSON الضخمة أو سعة IndexedDB. الحد الحالي للاستيراد 300 MiB وللصورة المضافة 20 MiB.

## قيود معروفة
- لا توجد مزامنة تلقائية بين الأجهزة؛ يتم النقل يدويًا بواسطة JSON.
- يدعم رفع PNG وJPEG وWebP وGIF وAVIF، وقد تختلف قدرة عرض AVIF حسب المتصفح.
- رمز PWA بصيغة SVG، ودون Service Worker؛ يمكن أن تختلف تجربة إضافة الشاشة الرئيسية بحسب المتصفح، ولا تتوفر تجربة Offline مضمونة.
- استيراد ملف كبير يحتاج ذاكرة كافية قبل بدء معاملة الاستعادة.
