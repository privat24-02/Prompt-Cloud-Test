عن التطبيق

Prompt Cloud تطبيق ويب شخصي لتنظيم التصنيفات والمطالبات النصية (Prompts) والصور المرجعية. يعمل الموقع حاليًا من خلال GitHub Pages.

مكان حفظ البيانات حاليًا

تُحفظ التصنيفات والمطالبات والصور التي تدخلها في مساحة التخزين المحلية داخل متصفحك باستخدام IndexedDB. لا يرفع الإصدار الحالي محتوى مكتبتك إلى Google Drive تلقائيًا، ولا يوفر مزامنة سحابية مفعّلة بعد.

يمكنك تصدير مكتبتك إلى ملف JSON واستيرادها يدويًا على جهاز آخر. يُحفظ ملف التصدير في المكان الذي تختاره على جهازك، وقد يحتوي على النصوص والصور كاملة.

خدمات الاستضافة

تستضيف GitHub Pages ملفات الموقع. قد تعالج GitHub بيانات تقنية تتعلق بطلبات زيارة الموقع، مثل عنوان IP ومعلومات الاتصال، وفقًا لسياساتها الخاصة. لا يعني ذلك أن مكتبتك المحلية تُرفع تلقائيًا إلى GitHub.

Google Drive — ميزة مخططة

يجري إعداد خيار اختياري لتسجيل الدخول بحساب Google ومزامنة مكتبتك عبر Google Drive. هذه الميزة غير مفعّلة في التطبيق الحالي. عند تنفيذها، ستتطلب موافقتك على الصلاحيات اللازمة، وستُحدَّث هذه السياسة قبل تشغيلها لتوضيح البيانات المنقولة وطريقة تخزينها وحذفها.

التحكم بالبيانات وحذفها

يمكنك تعديل المحتوى وحذفه من داخل التطبيق. ويمكنك إزالة البيانات المحلية عبر إعدادات المتصفح، لكن حذف بيانات الموقع قد يؤدي إلى فقدان مكتبتك نهائيًا إذا لم تحتفظ بنسخة احتياطية. حذف ملف JSON احتياطي محفوظ على جهازك مسؤولية صاحب الملف.
